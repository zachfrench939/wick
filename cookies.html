Wick

Cookies and storage

These pages do not set an HTTP cookie. The choice about optional page counts, the quiz, and an optional sign-in are stored in local storage. PECR covers that kind of storage as well as cookies. Session storage is not used. There is no advertising tag and no embedded video.

On this device

  • wick-best-score. Best scored points. Written when a scored game beats it. Kept until you clear site data. Practice does not write it.
  • wick-sound. Sound on or off, after you use the sound control. Kept until you clear site data.
  • wick-daily. Today’s chosen category, scored results, daily streak, one covered miss, and the dates used for the calendar. Kept until you clear site data. This is what lets the free game offer one scored category a day.
  • wick-device-id. A random id created when a scored result is sent, so the same browser is counted once per category that day. Kept until you clear site data. It is not created by opening the page, it is not used for GoatCounter, and signing in does not replace it.
  • wick-consent. Whether optional page counts are allowed, and the time of that choice. Kept for 180 days, then the question is shown again. Rejecting counts does not delete the quiz or an account session.
  • wick-auth-session. Only after an account session exists. Access token, refresh token, expiry, user id, and email. Removed on this device when you log out. The password is not stored. Anonymous play does not create it.

Optional GoatCounter count

Allowing optional counts can load one script, https://gc.zgo.at/count.js, and send one request to https://zachfrenchwickquiz.goatcounter.com/count. GoatCounter’s documentation says that visitor count does not set a cookie or local storage. Wick also refuses to load the script for the address #toggle-goatcounter, which is the case where that script would write a skipgc local storage flag.

The numbers are page loads Wick asks GoatCounter to record. They are not a count of unique people. A signed-in check reported individual pageview rows as off. The separate sessions switch in the dashboard was not confirmed.

GoatCounter’s own login

The operator dashboard is a different site and asks for a sign-in. GoatCounter’s documentation says that site uses cookies to remember the logged-in operator and to hold short on-screen messages. Those cookies are not set when someone plays Wick. Their exact names were not observed on wickquiz.com, so they are not listed here as if they were.

The privacy notice covers rankings, accounts, children, and the facts that are still missing. It does not claim that the site is legally compliant.
