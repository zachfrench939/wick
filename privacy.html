Privacy notice

This notice describes what the Wick pages in this project actually do. It is not a legal opinion, and it is not a statement that the site meets every UK requirement. Facts the operator still has to supply are listed at the end.

Storage and access technologies, including local storage, are covered by PECR as well as by data protection law where personal data is involved. The ICO’s storage and access guidance was finalised on 29 April 2026, after the Data (Use and Access) Act changes. One of the five exceptions can cover some aggregate statistics when the purpose is only to improve the service, people are told, and there is a simple free way to object. Wick does not rely on that exception. Optional page counts stay off until a visitor allows them. That is a choice for this site. It is not a claim that every analytics tool always needs consent.

Who is responsible

The pages do not name a controller, a postal address, or an email address. The public site wickquiz.com is served by GitHub Pages from the repository zachfrench939/wick. An older notice linked zachfrench939.github.io. That repository does not hold the wickquiz.com custom domain. Publishing location is not the same as a completed controller identification.

Playing without an account

Anyone can play, including children. The questions are written to be family-friendly. The site does not ask for an age. No children’s assessment or DPIA is included in this repository. Offering the quiz, and especially an optional email account, to children needs a decision by the operator under the Children’s Code before this should be treated as settled. This notice does not say that assessment has been done.

A scored daily game sends four things to the Supabase project hlnlkcdmtnbzouomcxcg: the day number, the category label, how many answers were right (0 to 100), and a random device id. Practice is not sent. The browser uses the project’s publishable key. That key is meant to be public. The anon role in the checked schema can insert a score and call two aggregate functions. It is not given a select grant on the score table in that schema. This notice does not repeat a service-role key.

On 7 November 2026 the project record showed region eu-west-2 (London, United Kingdom) and status active. The database timezone read as UTC. London is not described here as the EU. A contract, a processor role, and a lawful basis were not confirmed for this notice. The earlier notice’s “legitimate interests” sentence is withdrawn until the operator records a basis.

The same check found a scheduled job, wick-delete-scores-older-than-12-months, set for 03:15 UTC each day, deleting daily_scores rows older than 12 months. That confirms the job definition, not every past run, and not backups or hosting logs.

The random device id is created when a scored result is submitted, then kept until site data is cleared. It is a persistent identifier. This notice does not call it strictly necessary in the legal sense. It is not copied into an account, and it is not sent to GoatCounter.

Optional account

Email and password sign-up, sign-in, sign-out, and password reset are available and are not required to play. A public Auth settings read on 7 November 2026 showed email sign-in enabled, sign-up enabled, and mailer_autoconfirm false, so a new account needs an email confirmation before a session starts. Phone sign-in was off. This work did not change Auth settings and did not send a confirmation or reset email.

The password is sent to Supabase Auth and is not written into local storage by these pages. After a session exists, this device stores the access token, refresh token, expiry, user id, and email under wick-auth-session. Logging out removes that record from this device. The quiz keys stay. The pages do not read user_metadata to grant anything. There is no paid entitlement.

Confirmation and reset links are requested for https://wickquiz.com/auth.html only. Tokens that arrive in the address are removed from the bar after they are read. Whether the project’s Site URL and redirect allow-list match that address was not confirmed. Account deletion and a rights process are not built here. How long Auth keeps an email is not stated in this repository.

Optional page counts

If a visitor allows it, and only on wickquiz.com, the page can load https://gc.zgo.at/count.js and send one page-load count to https://zachfrenchwickquiz.goatcounter.com/count. The count is skipped when Do Not Track or Global Privacy Control is on, when the address has a query string, and on any other host, so local and preview visits are not sent. The payload is limited to a short allow-listed path, an empty referrer field, and a request to count the load rather than stitch a visit. Screen width and the query string are stripped before send. The page does not send the device id, email, answers, or password.

GoatCounter’s own documentation (privacy page dated 8 June 2025) says visitor counting does not use a cookie or local storage, that an in-memory combination of site, IP address, and user agent can last up to 8 hours for its default visit deduplication, that the operator is Martin Tournoij in Ireland, and that hosting is at Hetzner in Finland and Germany. Those are their statements. A cookieless counter is not automatically outside PECR.

A coordinator, while signed in, reported that the dashboard is login-only, the timezone is Europe/London, the connected domain is wickquiz.com, and individual pageview collection is off. Those settings were not changed. GoatCounter account email verification was still pending. Browser, system, location, and language collection switches, and the dashboard sessions switch, were not part of that check. The dashboard is not embedded on Wick and no GoatCounter API key is in these files. Login cookies for the GoatCounter site, described in their documentation as remembering a signed-in operator and short messages, are not set by the public Wick pages.
